# Prática de Programação em C

Uma pasta com códigos em C que fiz para praticar minha prática de programação.

## Exercícios

- **01-validador-cpf** — validação de CPF com cálculo dos dígitos verificadores
- **02-cadastro-carro** — cadastro de carros usando struct, com cálculo de autonomia
- **03-sistema-academico** — cadastro de alunos com nome, idade e nota, listagem, cálculo de média, busca e estatísticas da turma
- **04-gerenciador-arquivo** — menu para escrever, visualizar, sobrescrever e adicionar linhas em um arquivo .txt
